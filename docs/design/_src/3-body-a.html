03 · 自适应框架

三个维度决定一块屏幕长什么样

电视在 1080p、xhdpi 下的逻辑宽度只有 960dp，单看 WindowSizeClass 会被当成横屏平板。所以除了尺寸，还要单独判断输入方式和观看距离。三个维度互相独立，组合起来覆盖手机、折叠屏、平板、带键盘的平板、电视和投屏。

统一入口：一个 Activity，两个启动类别

手机桌面和电视桌面都启动同一个 MainActivity。去掉电视版的强制横屏，横竖屏交给传感器；configChanges 接管尺寸变化，折叠、分屏、拖动窗口时不重建 Activity，播放不中断。

DeviceProfile：三个维度合成一个 CompositionLocal

所有界面只读 LocalDeviceProfile，不再各自调用 calculateWindowSizeClass（现在手机端混用了两套 API）。输入方式随最后一次输入事件实时切换：平板接上蓝牙键盘按方向键，焦点框马上出现。

enum class InputMode { Touch, DPad, Pointer }
enum class Distance { Near, Far }

@Immutable data class DeviceProfile(
    val width: WidthClass,    // Compact … ExtraLarge
    val input: InputMode,
    val distance: Distance,
) {
    val isTv get() = distance == Distance.Far
    val navigation get() = when {
        isTv -> NavKind.TvRail
        width >= WidthClass.Large -> NavKind.RailExpanded
        width >= WidthClass.Medium -> NavKind.Rail
        else -> NavKind.Bar
    }
}

@Composable fun rememberDeviceProfile(): DeviceProfile {
    val size = currentWindowAdaptiveInfo().windowSizeClass
    val far = rememberIsTelevision()   // UiModeManager + FEATURE_LEANBACK
    val input = rememberLastInputMode() // KeyEvent / MotionEvent 的 source
    return remember(size, far, input) {
        DeviceProfile(size.toWidthClass(), input, if (far) Far else Near)
    }
}
