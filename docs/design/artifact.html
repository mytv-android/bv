03 · 自适应框架

三个维度决定一块屏幕长什么样

电视在 1080p、xhdpi 下的逻辑宽度只有 960dp，单看 WindowSizeClass 会被当成横屏平板。所以除了尺寸，还要单独判断输入方式和观看距离。三个维度互相独立，组合起来覆盖手机、折叠屏、平板、带键盘的平板、电视和投屏。

统一入口：一个 Activity，两个启动类别

手机桌面和电视桌面都启动同一个 MainActivity。去掉电视版的强制横屏，横竖屏交给传感器；configChanges 接管尺寸变化，折叠、分屏、拖动窗口时不重建 Activity，播放不中断。

DeviceProfile：三个维度合成一个 CompositionLocal

所有界面只读 LocalDeviceProfile，不再各自调用 calculateWindowSizeClass（现在手机端混用了两套 API）。输入方式随最后一次输入事件实时切换：平板接上蓝牙键盘按方向键，焦点框马上出现。

enum class InputMode { Touch, DPad, Pointer }
enum class Distance { Near, Far }

@Immutable data class DeviceProfile(
    val width: WidthClass,    // Compact … ExtraLarge
    val input: InputMode,
    val distance: Distance,
) {
    val isTv get() = distance == Distance.Far
    val navigation get() = when {
        isTv -> NavKind.TvRail
        width >= WidthClass.Large -> NavKind.RailExpanded
        width >= WidthClass.Medium -> NavKind.Rail
        else -> NavKind.Bar
    }
}

@Composable fun rememberDeviceProfile(): DeviceProfile {
    val size = currentWindowAdaptiveInfo().windowSizeClass
    val far = rememberIsTelevision()   // UiModeManager + FEATURE_LEANBACK
    val input = rememberLastInputMode() // KeyEvent / MotionEvent 的 source
    return remember(size, far, input) {
        DeviceProfile(size.toWidthClass(), input, if (far) Far else Near)
    }
}
04 · 色彩系统

颜色从种子色和封面里长出来

用 com.materialkolor:material-kolor 生成整套 Material 颜色角色。全局主题来自用户选的种子色（或 Android 12+ 的壁纸色），详情页、播放器和刷刷再用当前视频封面的颜色局部覆盖一层。这一页上的所有颜色都由同一套算法（material-color-utilities，material-kolor 移植的就是它）在浏览器里实时算出来，改种子色或风格就能看到效果。

封面取色：点一张封面

// 全局主题：用户种子色 / 壁纸色，PaletteStyle 和对比度来自设置
@OptIn(ExperimentalMaterial3ExpressiveApi::class)
@Composable fun BvTheme(prefs: ThemePrefs = LocalThemePrefs.current, content: @Composable () -> Unit) {
    val dark = prefs.darkMode.resolve(isSystemInDarkTheme())
    val seed = if (prefs.source == ThemeSource.Wallpaper) wallpaperSeedOr(prefs.seed) else prefs.seed
    DynamicMaterialExpressiveTheme(
        seedColor = seed,
        isDark = dark,
        isAmoled = prefs.pureBlack,                       // 影院纯黑
        style = prefs.paletteStyle,                       // 默认 PaletteStyle.Vibrant：保留品牌色相、饱和度高
        contrastLevel = prefs.contrast,
        specVersion = ColorSpec.SpecVersion.SPEC_2025,
        motionScheme = MotionScheme.expressive(),
        typography = bvTypography(LocalDeviceProfile.current),
        animate = true,
        content = content,
    )
}

// 局部主题：详情 / 播放器 / 刷刷。封面颜色在后台线程算，按 URL 缓存
@Composable fun CoverTheme(cover: String?, content: @Composable () -> Unit) {
    val seed by rememberCoverSeed(cover)              // null 时沿用全局 primary
    DynamicMaterialExpressiveTheme(
        seedColor = seed ?: MaterialTheme.colorScheme.primary,
        isDark = true, style = PaletteStyle.Fidelity, animate = true, content = content,
    )
}

suspend fun CoverSeedCache.get(url: String): Color? = cache.getOrPut(url) {
    val bitmap = imageLoader.execute(
        ImageRequest.Builder(context).data(url).size(112).allowHardware(false).build()
    ).drawable?.toBitmap()?.asImageBitmap() ?: return null
    withContext(Dispatchers.Default) { bitmap.themeColors(fallback = Color.Unspecified).firstOrNull() }
}

07 · 新入口「刷刷」

一直往下刷，刷到的每条都带着自己的颜色

「刷刷」是新的一级入口：全屏竖向翻页，一次一条，自动播放。每条视频的操作按钮、进度条和背后的氛围光都用它封面的颜色重新生成。左边的手机画面可以直接滚动。

// designsystem/focus/BvFocus.kt（示意；正式实现用 Modifier.Node）
fun Modifier.bvFocus(
    shape: CornerBasedShape = RoundedCornerShape(16.dp),
    focusedShape: CornerBasedShape = RoundedCornerShape(22.dp),
    scale: Float = 1.08f,
) = composed {
    val profile = LocalDeviceProfile.current
    var focused by remember { mutableStateOf(false) }
    // 触摸模式下不放大不描边，只有方向键 / 键盘导航时才显示
    val visible = focused && profile.input != InputMode.Touch
    val motion = MaterialTheme.motionScheme
    val s by animateFloatAsState(if (visible) scale else 1f, motion.fastSpatialSpec())
    val morph by animateFloatAsState(if (visible) 1f else 0f, motion.defaultSpatialSpec())
    val ring = MaterialTheme.colorScheme.primary
    this
        .onFocusChanged { focused = it.isFocused }
        .graphicsLayer { scaleX = s; scaleY = s }
        .focusRing(visible, ring, lerp(shape, focusedShape, morph))
        .focusable()
}
